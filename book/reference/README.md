## 唯一执行顺序

1. 读 `AGENTS.md`、`启动新书.txt`、`project_config.json`、`book/state.json`、`book/workflow.json`、`online/index.json`；遇身份、哈希或冻结冲突，停止检查。
2. 读 `book/state.json.inputs.canon` 指向的**最新不可变canon**和 `roadmap` 指向的路线；不要把同名旧文件当新版。
3. 按任务读本目录：`01_粮仓与资金账.md`（量、债、价格与买仓）、`02_人物知情与行动边界.md`（信息权限）、`03_承诺与知情清单.md`（预计兑现窗口）、`04_前五章滚动场景.md`（场景支持）。若与最新 canon/roadmap 冲突，以最新正式输入为准并记录待核事项。
4. 第一章使用最新 `book/briefs/CH001_*.json`，必须与最新 canon 和 roadmap 哈希匹配；调用 `brief-check` 后再准备 writer 资料。未定稿正文只在 `drafts/` 或 `book/incomplete/`，不能冒充 `book/chapters/`。
5. 完整稿 `candidate` → 实际正文反向检查/限信息读者审读 → `release-check` → `adopt` 冻结；每5章回看、每阶段全文回看；实际发布另行登记。
6. 重大阶段/输入变化必须用 `tools/online_state.py task` 和 `build-index`、`validate-index`，与有关文件一次 GitHub 提交、回读。
