# CH002章后记忆

CH002仍在CH001同一秋夜，未到清晨。裴穿上霍扔来的右旧鞋，鞋小顶趾，左脚仍为原新鞋；落在棚内的半张鸡蛋饼由霍拾起，后分食，章末已吃或含在嘴中，无整饼库存。两人循兽院草槽软梯下到旧草路，受程照夜阻挡后改入三河寨外无人的石沟，未进寨、未至白榆镇。末景裴、霍在沟底断口对面的落脚处，后方出口更窄；程立右侧斜石，两名青岫宗追手已至来路沟口，一人持灯、一人把铁链缠上前臂，尚未开打。追索循暴露软梯而来，不是远隔定位。

CH002裴误把兽朝上风的动作当作回祭堂，取石诱它随自己，兽拿回石片后仍改向。他未等霍放稳软梯便扑去拨开挂住兽的竹茬，滑倒夹梯，使霍右腕绞在梯绳、身体撞壁，竹排滚落暴露藏路；两人被上方人点名看见。梯有可由长尾抽解的活扣，逃时未能收回，仍留给追手。霍原想临时送出便回去，此后未能回；裴对此愧疚，解释“以为回祭堂”未获得谅解。

CH002霍右腕明显疼、肿，抓握和撑石受限，未诊断是否骨伤。自行草绳勒扎过紧，程以刀挑断，给粗布；霍绕颈托腕，裴帮拉布头，主要用左手。霍可从右侧土坡独走，停顿后仍问不经人家的路并一起入沟；避扶、责备“你什么也没想”仍在。分饼、抛绳是继续合作，不等于和解。剩余几尺草绳已给裴穿旧外衣作胸前布兜，未绑到兽踝；章末裴右手攥着兜边绳，不愿放兽。梯、钱、短刀均未收回；CH001相关遗失与掌伤黑刺仍查原文及其memory，未治疗完成。

CH002裴右掌指尖接触兽腹时只短暂再现踝痛与辨振，将自己踏动坠石绳造成的细响误当多处脚步。霍拨绳、裴松脚后看见来源，非成功探明伏兵。离手后没有持续异听，入沟时隔衣托兽，未增新能力，也不知道术式名与精确范围。程问“它教你听路”，只是猜测；霍只见他异常回望，未被告知血纹或其原理。追手没有现场获知这些。

CH002幼兽仍有右后踝深钉与铁箍，未断外圈、未治愈，左耳缺角；在水凹自己松开石片、踩住石片舔两次水，裴俯近又缩回并叼石，不是认主。章末鼻尖仍向上风，裴只观察到方向，其原巢、母兽、真正目的依旧未知；未取名，未主动救人。

CH002程照夜自报姓名，巡守三河寨后路。看见狗、羊圈和出门村人，吹短哨叫人退回；听裴说救兽、识出祭具后仍不允带兽下人居路，允人独走。随行入石沟是防他们转回寨子，帮霍松绳、托伤，不代表接受裴的全部立场。章末要求追手收链，理由是逼兽钻回羊圈会添乱，未承诺对抗宗门或长久同行。尚未解决追手与两伤者如何过险口的眼前局面。
